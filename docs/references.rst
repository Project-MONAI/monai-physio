Datasets
========

DirLab 4D-CT
------------

Public benchmark for respiratory motion:

* 10 cases with exhale and inhale phases
* 300 landmark points for validation
* `Website <https://www.dir-lab.com/>`_

Slicer-Heart-CT
---------------

Cardiac CT examples from 3D Slicer:

* Multiple cardiac phases
* Various pathologies
* `3D Slicer Website <https://www.slicer.org/>`_

Chest-CT
--------

Single-acquisition clinical chest CT:

* One static 3D volume, no gating
* From the AREN0534 trial on The Cancer Imaging Archive
* `TCIA dataset <https://doi.org/10.7937/TCIA.5M9S-6Y97>`_
* Citation: see ``data/Chest-CT/README.md``
